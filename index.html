05 / GOOD TO KNOW

A few notes
before you begin.

A closer look at the app behind the formations.

What is Fieldwork?

Fieldwork is a marching drill design app. Its workspace brings together a field canvas, performer and formation editing, set navigation, timing, and playback.

Which platform is shown here?

This tour shows the native Mac app, captured from a local development build. It does not establish a public release or Windows availability.

Are these real screenshots?

Yes. The images were captured in the running Fieldwork Mac app using the supplied drill0-1-curves.fieldwork show. The scroll sequence shows consecutive sets 59, 60, and 61. Crops and numbered markers help explain the interface.

Can I work with music?

The Mac build includes an audio waveform, a playhead, playback controls, and audio alignment controls. This tour shows the supplied show’s loaded waveform; it contains no audio or autoplay recording.

How are shows saved?

The native document format is .fieldwork. The Mac editor can save and reopen these documents. No additional import or export compatibility is promised by this prototype.

Where can I get Fieldwork?

This is an initial product-site prototype using a development build. A verified release destination and distribution details have not been supplied, so “Explore Fieldwork” opens the tour. Pricing and release availability are not announced here.
